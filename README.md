



Code accompanying Gozzo \& Isacson et al. 2026, "Paternal Piwi regulates sperm-borne mitosRNA and offspring mitochondrial metabolism."



This repository contains the analysis code for sperm small RNA (sRNA), testes, and embryo RNA sequencing data, along with the plotting scripts for all main and supplementary figures of the manuscript.



Both the small RNA and mRNA analyses are built on Seqpac, a workflow primarily developed for small RNA sequencing.







If you're interested in sRNA analysis workflows, check out our Seqpac vignette on GitHub: https://github.com/AlessoGozzo/seqpac
